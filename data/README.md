# Dataset Instructions

The dataset files are not included in this repository because they are large files provided by Kaggle.

## Download

Download the dataset from:

https://www.kaggle.com/competitions/playground-series-s6e11/data

## Required Files

Place these three files inside this folder:

- train.csv
- test.csv
- sample_submission.csv

After downloading, the folder structure should look like:

data/
├── train.csv
├── test.csv
└── sample_submission.csv
